##Week 1: Project Proposal & Initial UI/UX Design

Project Pitch — Intermediate Java Exam System

The goal of this project was to develop an interactive Java Exam System for students or anyone looking to practice intermediate-level Java programming concepts.
My initial plan was to create an exam application that would begin with a student information screen, where users could enter their full name, student ID, and school name. After entering their information, users would click a button to begin the exam.
The exam would consist of approximately 10 multiple-choice questions, each dedicated to one of the learning objectives covered in my intermediate Java programming course (CISC 191). Users would navigate through the questions, select their answers, and submit the exam once completed.
I also planned to implement a results screen that would display the student's performance across the different learning objectives.
The purpose of this project was to create an interactive learning tool that students could use to evaluate their understanding of intermediate Java concepts.

##Initial UI/UX Design

Before beginning the coding process, I created hand-drawn sketches to visualize how I wanted the application's interface and navigation to look.

My initial design included four main screens:
Student Information Screen: A form where users would enter their name, student ID, and school before beginning the exam.
Multiple-Choice Exam Screen: An interface displaying Java programming questions, answer options, and navigation buttons.
Exam Submission Screen: The final question screen, where users would submit their completed exam.
Learning Outcomes Evaluation Screen: A results page displaying the student's performance across the course learning objectives.
